# bmw-sales-dashboard
Interactive Power BI dashboard analyzing BMW global sales performance, revenue trends, regional insights, and product analytics using business intelligence and data visualization techniques.
BMW Global Sales Dashboard – Power BI
Project Overview

This project is a Power BI dashboard created to analyze BMW global sales performance using sales data across different regions, products, and time periods.

The goal of this dashboard is to transform raw sales data into clear business insights that help understand:

Revenue performance
Sales trends over time
Product performance
Regional comparisons
Customer purchasing behavior
